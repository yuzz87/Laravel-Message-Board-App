# Message Board App

Laravel API + React で作成した、認証付きメッセージ投稿アプリです。  
ユーザー登録・ログイン後にプロフィールを管理し、投稿の作成・編集・削除、保存、いいねができます。  
また、**プロフィール公開/非公開** と **投稿公開/非公開** を組み合わせた閲覧制御を実装しています。

## バックエンド設計で意識したこと

このアプリは、画面からではなく、**データ設計と権限設計から先に考える** 方針で作成しました。

設計の基本方針は次の通りです。

- Guest は公開情報のみ閲覧可能
- Account は自分の情報を操作可能
- 他人の非公開情報は閲覧不可
- 投稿の閲覧可否は `profiles.is_public` と `posts.is_public` の両方で判定
- 本人のみ、自分の非公開プロフィール・非公開投稿を閲覧可能
- 更新・削除は所有者のみ可能

## 現状の課題

- TypeScript の型設計がまだ弱く、型の共通化が不十分
- tokenが DevTools から見える状態で、認証管理に改善余地がある
- テストは手動確認が中心で、自動テストがまだ十分ではない

## 今後の改善方針

- 型定義を整理し、保守しやすい構成にする
- tokenの保存方法や認証フローを見直し、安全性を高める
- バックエンド・フロントエンドのテストを強化し、確認作業を効率化する
- UI/UXを改善し、完成度を高める
